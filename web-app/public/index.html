🏥 About Pharmacy

Pharmacy Management System

The primary aim of this Pharmacy Management System is to enhance safety, improve dispensing accuracy, and maintain a centralized inventory database for medicines, purchases, staff, and transactions.

Connected directly to MySQL Server for instantaneous multi-workstation data visibility in MySQL Workbench.
